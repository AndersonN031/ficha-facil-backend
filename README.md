Projeto com ideia de melhorar a qualidade de pegar ficha em postos de saúde

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
# run padrão
$ npm run start

# watch mode
# run em tempo real, é melhor que o padrão
$ npm run start:dev

# production mode
# run em produção, no momento não usar esse
$ npm run start:prod
```
